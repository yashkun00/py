# 🐍 Python Basic Arithmetic

A simple Python program demonstrating the **basic arithmetic operations** — addition, subtraction, multiplication, and division.

Perfect for beginners who are learning Python fundamentals. 🚀

---

## 📌 Overview

This project contains simple examples of mathematical operations using Python variables and the `print()` function.

### Operations Included

| Operation         | Symbol | Example        |
| ----------------- | :----: | -------------- |
| ➕ Addition        |   `+`  | `2 + 4 = 6`    |
| ➖ Subtraction     |   `-`  | `8 - 5 = 3`    |
| ✖️ Multiplication |   `*`  | `2 * 1 = 2`    |
| ➗ Division        |   `/`  | `12 / 2 = 6.0` |

---

## 💻 Code Examples

### ➕ Addition

```python
a = 2
b = 4

result = a + b
print("Result = ", result)
```

**Output:**

```text
Result =  6
```

### ➖ Subtraction

```python
c = 8
d = 5

result = c - d
print("Result = ", result)
```

**Output:**

```text
Result =  3
```

### ✖️ Multiplication

```python
e = 2
f = 1

result = e * f
print("Result: ", result)
```

**Output:**

```text
Result:  2
```

### ➗ Division

```python
x = 12
y = 2

divide_result = x / y
print("The divide of", x, "and", y, "is: ", divide_result)
```

**Output:**

```text
The divide of 12 and 2 is:  6.0
```
